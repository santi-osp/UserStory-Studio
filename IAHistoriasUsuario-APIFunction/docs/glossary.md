# Glosario

- **App Setting**: clave de configuración del host o de Options backend.
- **Acceso anónimo**: trigger HTTP que no exige autenticación de Azure Functions.
- **PAT**: Personal Access Token de Azure DevOps, transportado en `x-azdo-pat`.
- **Use Case**: orquestador de Application independiente de HTTP.
- **Gateway**: puerto de Application implementado por Infrastructure.
- **Requirement suite**: suite asociada a una HU/requisito.
- **Static suite**: suite con membresía explícita para Test Cases independientes.
- **DLLO/PRBS**: nombres de ambientes presentes en artefactos ARM; no prueban despliegue.
